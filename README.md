# 🍫 Pão de Mel — Site de Vendas

Site de vendas criado para divulgar e comercializar pães de mel artesanais, com atendimento direto via WhatsApp.

🔗 **[Acesse o site ao vivo](https://ramon-lopes.github.io/pao-de-mel-landing-page/)**

---

## 📋 Sobre o projeto

Landing page desenvolvida para apresentar os produtos, preços e diferenciais de uma confeitaria artesanal de pão de mel. O visitante pode conhecer os sabores disponíveis e entrar em contato diretamente pelo botão de WhatsApp para fazer o pedido.

---

## ✨ Funcionalidades

- Apresentação dos produtos com preços atualizados
- Destaque dos diferenciais do produto
- Botão de contato direto via WhatsApp
- Layout responsivo para celular e desktop

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

---

## 🚀 Como visualizar localmente

```bash
# Clone o repositório
git clone https://github.com/ramon-lopes/pao-de-mel-landing-page.git

# Abra o arquivo no navegador
cd pao-de-mel-landing-page
# Abra o index.html no seu navegador preferido
```
